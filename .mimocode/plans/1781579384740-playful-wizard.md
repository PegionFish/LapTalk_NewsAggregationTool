## 修复方案

### U1: 分类Tab badge回填

**原因**：`topic_category` 字段在 `calculate_priority` 中已修复写入，但历史数据未回填。

**方案**：页面首次加载时自动调用 `populate-topic-categories` 端点。

**文件**：`news-web/frontend/src/pages/ArticleSearch.tsx`

```tsx
// 在 loadCategoryStats 回调中，先触发回填再查统计
const loadCategoryStats = useCallback(async () => {
  try {
    await api.populateTopicCategories(); // 触发回填
    const res = await api.getTopicCategories();
    setCategoryStats(res.categories || {});
  } catch { /* ignore */ }
}, []);
```

### U2: HTML实体解码

**原因**：RSS源返回的标题含HTML实体（`&#8217;`、`&#8216;`等），前端直接渲染。

**方案**：新建工具函数 `decodeHTMLEntities`，在渲染标题时调用。

**文件**：`news-web/frontend/src/utils/html.ts`（新建）

```typescript
const el = typeof document !== 'undefined' ? document.createElement('div') : null;
export function decodeHTMLEntities(text: string): string {
  if (!el) return text;
  el.textContent = text;
  return el.textContent || text;
}
```

**文件**：`news-web/frontend/src/pages/ArticleSearch.tsx`

```tsx
// 导入
import { decodeHTMLEntities } from '../utils/html';

// 标题渲染处（约第215行）
{decodeHTMLEntities(a.title)}

// 右侧标题渲染处（约第329行）
{decodeHTMLEntities(selected.title)}
```

### U3: 日期列宽度修复

**原因**：日期列 `width: 60` 太窄，"06-15" 被迫换行。

**方案**：增加列宽 + `whiteSpace: nowrap`。

**文件**：`news-web/frontend/src/pages/ArticleSearch.tsx`

```tsx
// 表头（约第182行）
<th style={{ ...thStyle, width: 72, whiteSpace: 'nowrap' }}>日期</th>

// 日期单元格（约第254行）
<td style={{ padding: '10px 12px', color: 'var(--text-muted)', fontSize: 11, whiteSpace: 'nowrap' }}>
  {a.published?.slice(5, 10) || a.fetched?.slice(5, 10)}
</td>
```

### U4: AI分析loading态精简

**原因**：loading态占据约60px高度的独立卡片，挤压下方评语区。

**方案**：将loading态改为单行内联spinner，减少高度。

**文件**：`news-web/frontend/src/pages/ArticleSearch.tsx`

```tsx
// 替换原来的loading卡片（约第496-510行）
{analyzing && !aiAnalysis ? (
  <div style={{
    fontSize: 12,
    color: 'var(--text-muted)',
    padding: '8px 12px',
    display: 'flex',
    alignItems: 'center',
    gap: 6,
  }}>
    <i className="fas fa-spinner fa-spin" style={{ color: 'var(--accent)', fontSize: 11 }} />
    分析中...
  </div>
) : ...}
```

### U5: 评语提交按钮loading态

**原因**：提交时按钮无视觉反馈，用户可能重复点击。

**方案**：`CommentPanel.tsx` 已有 `submitting` 状态和 spinner，确认按钮 disabled 生效。

**检查**：当前代码第131行 `disabled={!user || !draft.trim() || submitting}` 已正确处理，第142行 `{submitting ? <i className="fas fa-spinner fa-spin" /> : '发布'}` 也有spinner。无需修改。
