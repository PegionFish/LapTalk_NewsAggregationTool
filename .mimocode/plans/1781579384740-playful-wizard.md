## F1: 审核评语系统（多级评语 + 点赞）

### 1.1 数据库变更 — `news_db.py` `_init_db()` + `migrations.py`

新增两张表：

```sql
CREATE TABLE IF NOT EXISTS article_comments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    article_id INTEGER NOT NULL REFERENCES articles(id) ON DELETE CASCADE,
    user_id INTEGER,
    username TEXT DEFAULT 'anonymous',
    parent_id INTEGER REFERENCES article_comments(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS comment_likes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    comment_id INTEGER NOT NULL REFERENCES article_comments(id) ON DELETE CASCADE,
    user_id INTEGER NOT NULL,
    created_at TEXT NOT NULL,
    UNIQUE(comment_id, user_id)
);

CREATE INDEX IF NOT EXISTS idx_comments_article ON article_comments(article_id);
CREATE INDEX IF NOT EXISTS idx_comments_parent ON article_comments(parent_id);
CREATE INDEX IF NOT EXISTS idx_comment_likes_comment ON comment_likes(comment_id);
```

在 `_init_db()` 中以迁移方式添加（幂等）。

### 1.2 后端DB方法 — `news_db.py`

```python
# Article 级评语
def add_comment(self, article_id, user_id, username, content, parent_id=None) -> dict
def get_comments(self, article_id) -> list  # 树形结构，含点赞数
def delete_comment(self, comment_id, user_id) -> bool
def edit_comment(self, comment_id, user_id, content) -> bool
def toggle_comment_like(self, comment_id, user_id) -> dict  # 返回 {liked: bool, count: int}
```

### 1.3 后端API — 新建 `api/comments.py`

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/articles/{id}/comments` | GET | 获取文章评语列表（树形） |
| `/api/articles/{id}/comments` | POST | 添加评语 `{content, parent_id?}` |
| `/api/comments/{id}` | PATCH | 编辑评语 `{content}` |
| `/api/comments/{id}` | DELETE | 删除评语 |
| `/api/comments/{id}/like` | POST | 点赞/取消点赞 |

在 `main.py` 注册 `comments_router`。

### 1.4 前端API — `api/client.ts`

```typescript
getArticleComments: (articleId: number) => fetchJSON<Comment[]>(`/articles/${articleId}/comments`)
addArticleComment: (articleId: number, content: string, parentId?: number) =>
  fetchJSON<Comment>(`/articles/${articleId}/comments`, { method: 'POST', body: JSON.stringify({ content, parent_id: parentId }) })
editComment: (id: number, content: string) =>
  fetchJSON<{ok: boolean}>(`/comments/${id}`, { method: 'PATCH', body: JSON.stringify({ content }) })
deleteComment: (id: number) =>
  fetchJSON<{ok: boolean}>(`/comments/${id}`, { method: 'DELETE' })
toggleCommentLike: (id: number) =>
  fetchJSON<{liked: boolean, count: number}>(`/comments/${id}/like`, { method: 'POST' })
```

### 1.5 前端类型 — `types/index.ts`

```typescript
export interface Comment {
  id: number;
  article_id: number;
  user_id: number;
  username: string;
  parent_id: number | null;
  content: string;
  created_at: string;
  updated_at: string;
  like_count: number;
  liked_by_me: boolean;
  replies?: Comment[];
}
```

### 1.6 前端组件 — 新建 `components/CommentPanel.tsx`

在 ArticleSearch 右侧详情面板底部（AI分析下方）增加评语区：
- 评语文本输入框 + 提交按钮
- 评语列表（树形，缩进显示回复）
- 每条评语：用户名 + 时间 + 内容 + 点赞按钮（带计数） + 删除按钮（仅自己的）
- 评语输入框旁显示当前用户信息

## F4: 评分排序

### 4.1 后端API — `api/articles.py` 修改

`list_articles` 新增 `sort` 参数：
- `sort=fetched_desc` (默认，按抓取时间降序)
- `sort=score_desc` (评分从高到低)
- `sort=score_asc` (评分从低到高)
- `sort=date_desc` (发布日期降序)

### 4.2 前端 — ArticleSearch.tsx

在搜索栏右侧增加排序下拉框：
```
[默认排序 ▼] → 默认排序 / 评分最高 / 评分最低 / 最新发布
```

### 4.3 关键文件
- `news-web/backend/api/articles.py` — sort参数
- `news-web/frontend/src/api/client.ts` — (无需改，已透传params)
- `news-web/frontend/src/pages/ArticleSearch.tsx` — 排序选择器
